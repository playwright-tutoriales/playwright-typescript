## ⚙️ Requisitos

- [Node.js](https://nodejs.org/) 18 o superior
- Editor de código (recomendado: VS Code)

## 🚀 Cómo usar el código

```bash
# 1. Clona el repositorio
git clone https://github.com/playwright-tutoriales/playwright-typescript.git

# 2. Entra en la carpeta del video que quieras
cd playwright-typescript/01-primer-test

# 3. Instala las dependencias
npm install

# 4. Descarga los navegadores de Playwright (solo la primera vez)
npx playwright install

# 5. Ejecuta los tests
npm test
```
