# Capas support, config y data

- **support:** `CustomWorld`, hooks de apertura y cierre del navegador, lector de configuración y lector de CSV.
- **config:** un JSON por ambiente en `src/config`. El ambiente se elige con la variable `ENV`.
- **data/csv:** datos de prueba por caso. Los escenarios solo mencionan el nombre del caso.

**Secretos:** nunca en el repositorio. Solo `.env.example` se sube; `.env` está ignorado.
